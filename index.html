RadarCat 댓글 봇 (RadarCat Comment Bot)

레이더캣(Radarcat)이 만드는 인디 게임 채널의 유튜브 댓글 알림·답장 도우미 · 개인 개발자 김민수

무엇을 하는 프로그램인가요?

RadarCat 댓글 봇은 내 유튜브 채널(@radarcatgg) 영상에 새 댓글이 달리면, 내 텔레그램으로 알려 주고 버튼 한 번으로 답글을 달 수 있게 해 주는 윈도우 PC용 프로그램입니다.

  • 새 댓글이 달리면 텔레그램으로 영상 제목 · 작성자 · 댓글 내용 카드가 옵니다.
  • 카드의 버튼으로 초안 그대로 답장, 직접 입력, 건너뛰기, 작성자 무시를 고릅니다.
  • 원하면 지정한 키워드가 들어온 댓글에만 자동으로 답글을 다는 모드도 켤 수 있습니다(기본은 꺼짐, 속도 제한·중복 차단 적용).
  • 같은 댓글에 두 번 알림이나 두 번 답글이 가지 않도록 기록을 남깁니다.

어떻게 동작하나요?

  1. 프로그램은 사용자 본인의 PC에서 직접 실행됩니다. 개발자가 운영하는 서버는 없습니다.
  2. 유튜브 댓글 조회와 답글 게시는 YouTube Data API v3와 Google OAuth 2.0을 사용합니다. 사용자가 Google 동의 화면에서 직접 권한을 허용한 계정으로만 동작합니다.
  3. 댓글 기록과 인증 정보는 사용자 PC 안에만 저장됩니다.
  4. 알림을 켠 경우에만, 알림 내용이 사용자가 지정한 텔레그램으로 전송됩니다.

누가 쓰나요?

현재는 레이더캣 채널 운영자(개발자 본인)가 자기 채널의 댓글을 관리하기 위해 쓰는 개인용 도구입니다. 요청이 있으면 같은 방식으로 다른 크리에이터가 자기 채널에 쓸 수 있게 정리해 공유할 예정입니다.

  • 서비스 약관 — 이용 조건과 책임 범위

이 프로그램은 YouTube API 서비스를 사용합니다. 사용자는 YouTube 서비스 약관의 적용을 받으며, Google의 정보 처리에 대해서는 Google 개인정보처리방침을 따릅니다. 개발자는 YouTube 또는 Google과 제휴·후원·보증 관계가 없습니다.

RadarCat Comment Bot is a personal Windows desktop helper that notifies the creator of the RadarCat YouTube channel (@radarcatgg) about new comments and lets them reply with one tap. It runs on the user's own PC using YouTube Data API v3 with the user's own OAuth consent; no developer server is involved. Privacy Policy and Terms of Service are linked here.
