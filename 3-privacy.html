레이더캣(RadarCat) 댓글 봇 개인정보처리방침

시행일 2026년 11월 19일 · 버전 1.0 · 운영자 김민수(개인 개발자, 레이더캣 / Radarcat) · 문의 minsu920109@gmail.com

레이더캣 댓글 봇(이하 "본 앱")은 운영자 본인이 자신의 유튜브 채널(RadarCat, @radarcatgg)에 달리는 댓글을 확인하고 답글을 다는 목적으로 만든 개인용 데스크톱 프로그램입니다. 본 앱은 이용자의 윈도우 PC에서 직접 실행되며, 운영자가 별도의 서버를 두고 이용자 데이터를 수집·보관하지 않습니다.

1. 적용 범위

이 방침은 본 앱(실행 파일과 설정 파일 일체)에 적용됩니다. 본 앱을 안내하는 웹 페이지(앱 소개·본 방침·서비스 약관)는 GitHub Pages(GitHub, Inc.)에 정적 페이지로 게시되어 있으며, 해당 페이지 방문 시 GitHub 서버에 남는 접속 기록은 GitHub의 정책을 따릅니다. 그 페이지들 자체는 이용자를 식별하는 정보를 수집하지 않습니다.

2. 처리하는 정보와 처리 목적

구분 처리하는 정보 목적
YouTube API로 조회 이용자 채널의 영상 목록(영상 ID, 제목), 영상에 달린 최상위 댓글(댓글 ID, 댓글 본문, 작성자 표시 이름, 작성자 채널 ID, 작성 시각), 영상 소유 채널 확인 정보 새 댓글 감지, 알림 표시, 답글 대상 확인
인증 정보 OAuth 2.0 클라이언트 ID·클라이언트 보안 비밀(client_secret.json), 액세스 토큰·리프레시 토큰(token.json) 이용자 본인 계정으로 YouTube API를 호출하기 위한 인증
앱 운영 기록 처리한 댓글 ID, 알림·답글 게시 여부, 무시(mute) 목록, 실행 로그 중복 알림·중복 답글 방지, 동작 확인
알림 설정 텔레그램 봇 토큰과 chat_id(.env) 새 댓글을 이용자 텔레그램으로 알리기 위한 전송

처리하지 않는 정보: 구글 계정 비밀번호, 이메일 내용, 연락처, 위치 정보, 결제 정보, 주민등록번호, 광고 식별자. 본 앱은 비밀번호를 요청하거나 저장하지 않으며, 로그인은 Google의 OAuth 동의 화면에서만 이루어집니다.

3. 처리 방식과 저장 위치

  1. 본 앱은 이용자 PC에서만 동작하며, 데이터는 이용자 PC의 앱 폴더 안에만 저장됩니다(token.json, state/bot_state.db, logs/bot.log, .env, config.json).
  2. 운영자는 이용자의 댓글·토큰·로그를 전송받거나 열람하지 않습니다. 운영자가 운영하는 수집 서버는 없습니다.
  3. 본 앱이 외부로 보내는 것은 ① Google YouTube Data API 요청, ② 이용자가 지정한 텔레그램 봇을 통한 알림 메시지, 두 가지뿐입니다.

4. 제3자 제공 및 처리 위탁

본 앱은 이용자 정보를 제3자에게 판매·대여·제공하지 않으며, 처리 업무를 위탁하지 않습니다. 다만 서비스 제공에 필요한 범위에서 아래 두 사업자의 API를 호출합니다.

  • Google LLC — YouTube Data API v3 호출(조회·답글 게시). Google의 처리 방침은 Google 개인정보처리방침을 따릅니다.
  • Telegram — 새 댓글 알림 메시지 전송. 메시지에는 영상 제목, 댓글 작성자 표시 이름, 댓글 본문, 키워드 일치 여부가 포함됩니다.

국외 이전 고지

이전받는 자 국가 항목 목적 시기·방법 보유 기간

이용자는 텔레그램 알림 기능을 쓰지 않으면(알림 설정을 비우면) 해당 국외 이전은 발생하지 않습니다.

5. 보유 기간과 파기

  • 댓글 처리 기록(state/bot_state.db): 이용자가 파일을 삭제할 때까지 보관. 파기 방법은 앱 종료 후 파일 삭제입니다.
  • 실행 로그(logs/bot.log): 최근 3개 파일(파일당 최대 2MB)만 남기고 오래된 파일은 자동 삭제됩니다.
  • 인증 토큰(token.json): 이용자가 Google 계정 권한을 삭제하거나 파일을 삭제할 때까지 보관. 파기 방법은 token.json 삭제 또는 아래 6항의 권한 삭제입니다.
  • 텔레그램 봇 토큰·chat_id(.env): 이용자가 값을 지우거나 파일을 삭제하면 파기됩니다.
