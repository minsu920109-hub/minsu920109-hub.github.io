제1조 (목적)

본 약관은 레이더캣 댓글 봇(이하 "본 앱")의 이용 조건과 절차, 운영자와 이용자의 권리·의무를 정하는 것을 목적으로 합니다.

제2조 (정의)

  1. "본 앱"이란 운영자가 제공하는 윈도우 PC용 프로그램(실행 파일, 설정 파일, 안내 문서 일체)을 말합니다.
  2. "이용자"란 본 앱을 자신의 PC에 설치해 사용하는 사람을 말합니다.
  3. "이용자 채널"이란 이용자가 본 앱에 연결한 자신의 YouTube 채널을 말합니다.

제3조 (서비스의 내용)

  1. 본 앱은 이용자 채널의 영상에 달린 새 최상위 댓글을 주기적으로 확인하고, 이용자가 지정한 텔레그램으로 알림을 보냅니다.
  2. 이용자는 텔레그램 버튼 또는 명령으로 댓글에 답글을 게시할 수 있습니다.
  3. 이용자가 선택적으로 켜는 키워드 자동 답글 기능은 정해진 키워드·문구·속도 제한·중복 차단 조건 안에서만 동작합니다.
  4. 본 앱은 YouTube Data API v3만 사용하며, 비공식 크롤링이나 계정 자동 로그인 방식을 쓰지 않습니다.

제4조 (YouTube 약관에 대한 동의)

본 앱을 이용함으로써 이용자는 YouTube 서비스 약관에 구속되는 데 동의하게 됩니다. 본 앱은 YouTube API 서비스를 사용하며, 이용자는 YouTube API 서비스 약관, YouTube API 서비스 개발자 정책, Google의 API 서비스 사용자 데이터 정책이 적용됨을 인정합니다.

제5조 (이용 조건)

  1. 본 앱은 이용자 본인의 채널과 본인의 PC, 본인의 텔레그램 계정에서 사용하는 것을 전제로 합니다.
  2. 이용자는 본 앱을 설치·실행하기 전에 자신의 Google 계정으로 OAuth 동의 절차를 직접 진행해야 하며, 이때 요청되는 권한(youtube.force-ssl: 댓글 조회 및 답글 작성을 포함한 채널 관리 권한)의 범위를 확인해야 합니다.
  3. 이용자는 언제든지 Google 계정 설정에서 본 앱의 접근 권한을 삭제할 수 있고, 그 경우 본 앱의 기능은 즉시 동작하지 않습니다.

제6조 (이용자의 의무)

  1. 이용자는 자신이 게시한 답글의 내용에 대해 스스로 책임을 집니다.
  2. 이용자는 YouTube의 스팸 정책 및 커뮤니티 가이드를 준수해야 하며, 반복적·기계적·기만적 댓글이나 링크 도배, 타 채널 영상에 대한 홍보성 댓글 작성에 본 앱을 사용해서는 안 됩니다.
  3. 자동 답글 기능을 켜는 경우, 이용자는 문구와 속도 제한을 채널 상황에 맞게 설정해야 하며 운영자는 그 결과에 대해 책임지지 않습니다.
  4. 이용자는 인증 파일(client_secret.json, token.json), 봇 토큰(.env), 상태 DB(state/bot_state.db)를 제3자와 공유하거나 공개된 장소에 업로드해서는 안 됩니다.
  5. 이용자는 본 앱을 제3자의 계정·채널에 무단으로 연결하거나, 법령 또는 제3자의 권리를 침해하는 목적으로 사용해서는 안 됩니다.

본 앱의 코드와 문서에 대한 권리는 운영자에게 있습니다. 본 앱이 사용하는 YouTube 데이터와 상표는 각 권리자(YouTube, Google)에게 있으며, 운영자는 YouTube 또는 Google과 제휴·후원·보증 관계가 없습니다.

  1. 운영자는 본 앱의 기능을 변경하거나 배포를 중단할 수 있습니다.
  2. YouTube API의 변경·할당량 제한·정책 변경, Google 계정 또는 채널의 상태 변화로 본 앱이 동작하지 않을 수 있으며, 운영자는 이를 보장하지 않습니다.

  1. 본 앱은 있는 그대로(as-is) 제공되며, 특정 목적에의 적합성·무결성·무중단 동작을 보증하지 않습니다.

  3. 본 조는 관련 법령상 제한할 수 없는 책임까지 배제하지 않습니다.
